# Site da Dra. Luana Santos

Projeto Next.js simples com informações sobre a Dra. Luana Santos — fisioterapeuta em Uberlândia.

Para instalar dependências e iniciar o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

O site usa o App Router do Next.js e um formulário de contato que abre o cliente de email (mailto).
